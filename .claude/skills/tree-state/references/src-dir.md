# `src/felizjueves/`

Moved verbatim from `.claude/CLAUDE.md`, "The state of the tree, its table" (indexed by `../SKILL.md`).

**importable, and small.** **The layout** (milestone 18, #501–#515): the package root holds only `__init__.py`, `spec.py`, `engine.py` and `levers.py`, and every other module sits in a package — `ao/` (shells, primitive pairs, the density and ket records), `mmd/` (McMurchie–Davidson: `hermite`, `e_fragment`, `recurrence`, the `[p\|q]` builder `kernel`), `hgp/` (the HGP recurrence), `plan/`, `ir/` (the IR in `__init__`, `interp`, `passes`, `lower`, `lever_ladder`), `emit/`, `eri/` (the shared ERI layer: `eri`, `hgp_drive`, `schwarz`, `kernel_schwarz`, `kernel_pair_bound`, `launch_common`; and one package per build: `j_coulomb/` (the J chain, its launch plan and `levers/`), `k_exchange/` (MMD `K`, `kblock`, `kdup`, `kernel_record_bound` and `levers/`), `fock/` (the fused `F`, its stream, walker and `levers/`), `hjk/` (the split HGP `J`/`K`) and `density_fit/` (the metric and `(mn\|P)`)), `one_electron/` (`S`, `T`, `V`, `SX`, the dipole `MU` (`kernel_mu`, `multipole`) and their host references), `gradient/` (the d1 kernels `kernel_g1e`, `kernel_gjab`, `kernel_gk`, the dipole and quadrupole gradients `kernel_gmu`, the fused HGP `F` gradient `kernel_gf`, the HGP `V` gradient `kernel_ghv` and their host reference `host`), `hessian/` (the d2 Coulomb Hessian `kernel_hjab`, the ket derivative densities `kernel_hdq`, the d2 exchange Hessian `kernel_hkx` and their host reference `host`; the d1 exchange derivative matrix `kernel_kx` (`kx1_` / `kxc_`, #689) and its host reference `host_kx`; the Coulomb derivative matrix's ip1 bra half `kernel_jx` (`Target.JX` at d1, #688) and its host reference `host_jx`; the d2 one-electron `kernel_h1e` and its host reference `host_1e`; the d2 DF metric `kernel_d2metric` and its host reference `host_df`; the d2 three-center DF `kernel_d2eri3` and its host reference `host_eri3`; the d1 one-electron derivative matrices `kernel_ip1e`, #687, whose host reference is `gradient.host`'s `*_ip1` / `potential_rinv`), `performance/` (the measured store and driver, the gate, ceilings, dispatch and the reports), `literature/` and `reference/`. `test/test_root_layout.py` (fast tier) refuses any other module at the root. Below, a module is named by its path under `src/felizjueves/` where it moved. `spec.py` is `Spec`, the frozen key every later subsystem joins on; since #150 its `am` is a quartet for `Target.J` and a pair `(la, lb)` for `Target.DQ` and `Target.JAB` (`AM_LENGTH`), a pair target never batched; since #232 `Operator` also has `OVERLAP`, `KINETIC` and `NUCLEAR`, tied by `OPERATOR_OF` to the pair targets `Target.S`, `T` and `V`, and the batch ban is stated per target (`_PAIR_BATCH_REFUSAL`: structural for `DQ`, `JAB`, `S`, `T`; by decision for `V`, which has Hermite targets); since #196 `Target.K` is a quartet whose `am` is `(la, lc, lb, ld)`, the two Hermite pairs bra first (`kernel.k_spec(L)` gives each `L`'s class, with `pq_spec`'s split), batched exactly as `J` is. `literature/` loads published tables and scores a candidate against them: `tables`, `rules` (`Agreement`, `AtOrUnder`, `ExactGivenInputs` — which since #108 can carry a `refused` decision instead of inputs, scoring UNSET, never PASS), `scoreboard`, `limits`, `claims`. `plan/` (below) computes the Table 1–3 cells it scores. `mmd/kernel.py` builds the `[p\|q]` kernel as IR (`ir/__init__.py`, checked by `ir/interp.py`); `emit/` spells it for each vendor (`python -m felizjueves.emit` is the generator CLI); `build_pq_kernels` builds a split class's batch kernels, each `ir.passes.atomize`d. `ir.Fragment` / `ir.Inline` (#149) are a device-code block with a checked binding contract, one level only (no nested `Inline`); `mmd/e_fragment.py` (#152) is the undressed `E` as fragments (the block composed at build time from one axis builder; every entry one `Weighted`, the seed `exp(+ζ X_PA X_PB)`); `eri/j_coulomb/kernel_dq.py` (#153) and `eri/j_coulomb/kernel_jab.py` (#154) are the pre-contraction and bra-transform-and-scatter kernels that inline it, each with its own layering rule that keeps it off `ao`, `interp`, `emit`, `device` and `reference/`. `one_electron/kernel_s.py` (#237), `one_electron/kernel_t.py` (#238) and `one_electron/kernel_v.py` (#239) are the one-electron kernels, one thread per record with `kernel_jab`'s scatter rule and no prefactor formed: `S` inlines `e_fragment.overlap_fragment` (the `t = 0` column, dead entries dropped by `_live`), `T` `kinetic_fragment` (the axis bodies at `lb + 2`), and `V` `block_fragment` plus `recurrence.fundamental_prelude` / `recurrence_body` over `plan(v_spec(la, lb))`'s DAG, the plan layer's first non-J consumer, with the nuclei serial; Every kernel's Boys is one IR statement, `ir.Boys(dst, top, t)` (#301; `Fn.BOYS` and #266's `Kernel.wide_boys` are gone), filling a local fp64 `boys[0..top]` that each fundamental reads, spelled `fj_boys<top>(T, boys);`. Every kernel takes its per-record arrays as plain positional parameters. The one-electron `S`, `T`, `V` and `SX` call the record weight `s_ab` (as `V` and Schwarz always did; `S`, `T` and `SX` said `s` beside the output `S`) and take each record vector as three flat arrays, one per axis (`pa_x pa_y pa_z`, `pb_*`, `V`'s `p_*`; `kernel_s.pa_name`); every other kernel takes vectors interleaved `[n_rec, 3]` (`XPA[n_rec, 3]`). #424, #422 and #421 moved `S`, `T`, `V`, `SX`, Schwarz, `DQ`, `JAB` and `K` to per-axis arrays in one by-value `PrimPairSoA` struct, and all three were reverted, so there is no `ir.Bundle`, no `Kernel.bundled` and no `include/felizjueves/prim_pair.h`. A consumer that wants a per-axis layout asks for it after the build instead: `ir.passes.split_axes(kernel, {"XPA": ("pa_x", "pa_y", "pa_z"), ...})` turns each named `[n, 3]` parameter into three flat ones under the consumer's names, every `X[i, d]` read as `x_d[i]`, held bit-for-bit to the interleaved kernel in the interpreter (`test_passes.py`; DQ, JAB, `[p\|q]`); the builders' interleaved default is untouched, no struct, plain positional parameters. Likewise `ir.passes.transpose(kernel, ("D",))` stores a 2-D array parameter with its extents swapped, every `X[i, j]` read as `X[j, i]`: applied to `DQ` (which writes `D`) and `[p\|q]` (which reads it), `D` becomes `[n_q, n_ket]`, so a warp's lanes, consecutive kets, read consecutive doubles (`[Fock, §4.2]`'s "transposed before kernel launches to ensure contiguous reads"); held bit-for-bit in the interpreter (`test_passes.py`: DQ both densities, `[p\|q]`, composed with `split_axes` and `atomize`), compiled under both compilers (`test_emit_gpu.py`), the builders' row-per-ket default untouched, not run on a card here (FreeBreakfast's J build is its consumer). `build_dq_kernel(cls, density="ao")` (`dq_{lc}_{ld}_ao`, `AO_PARAMS`) reads the AO density in place, `Dao[off_c[k] + i, off_d[k] + j]`, `JAB`'s addressing, instead of the host's `Dcd[pair[k], r]` gather: `==` the default interpreted for every class (ss)–(ff), the default untouched, not run on a card (`j_engine.md`, step 2). `eri/k_exchange/kernel_k.py` (#198, #203; its own `k_builder` layering rule, off `ao`, `interp`, `reference/`, `emit` and `device`) is the exchange kernel, `build_k_kernel` one batch and `build_k_kernels` a split class as `ir.passes.atomize`d partial-sum batch kernels: the plan, DAG, schedule and thread mapping are `J`'s, both `E` fragments are inlined, `I` and the `K` accumulator share one shared array (`(ff\|ff)` fits 48 KiB, `(gs\|gs)` does not), the screen is `J`'s `break` on `Ip · Iq · maxD` with the kets sorted by `Iq` alone (`NO_DENSITY_KEY`, citing `[Fock, §4.3.1]`), and the recompute form, which `[JEngine, v2, §6]` says has more merit for `K`, is named, not built. `eri/k_exchange/kdup.py` (#202; its own `count` rule, plan only) counts the work a split duplicates, `J` against `K`, per primitive quartet: K's is the larger at every split cell, by two to four orders of magnitude on the subgrid. **Engine #2, the HGP fused `F`** (milestone 12; `docs/implementation/hgp_fock.md`): `hgp/` (`vrr.py`, `hrr.py`, `cost.py`, `mmd/recurrence.py`; layering rules `hgp` and `hgp_builder` keep it off `plan/` and `reference/`, pin 11), `eri/fock/kernel_f.py` (#282, #283; rule `f_builder`, off `plan`, `ao`, `reference/`, `interp`, `emit`, `device`: the fused kernel, `pack`, `density_blocks`, `close`, `derive_weights`, `degeneracy`, `MAX_PRIM_PAIRS = 128` a refusal; staging per thread because the IR has no barrier, #333), `eri/fock/launch_f.py` (#285, rule `f_launch`: `f_launches()` → `FPlan`, the pair stream, its bound injected; it takes the stable sort and the bound check from `launch_common`, #504 (#328), and takes the density and `tau` checks from `ao.density`, #503), `eri/fock/walk_f.py` (#286, rule `f_walk`: the oracle, the plan read by duck type, the launch injected), `eri/fock/fock.py` (#275: `G = J − K/2` by every ordered quartet at weight 1, the `eri=` slot injected, the symmetry witness) and `eri/hgp_drive.py` (#281, rule `hgp_adapter`: HGP's `eri_block` interpreted, Boys injected), and `engine.py` (#292, rule `engine`: `Engine`, `Mmd(pq=)`, `Hgp(boys=)`; the one module that names both engines, beside the two generators `emit.__main__` and `measured`, which may name each only by its kernel builder (`test_layering.py`'s `GENERATORS`, #287, #288); its docstring's pushed-back-down list is the milestone's primary report, #327). **The split HGP `J`/`K`** (milestone 14; `hgp_fock.md`, "The split cell"): `spec.Engine`, `NATIVE_ENGINE`, `Spec.engine` and `Spec.target_slot` (#401; `_ENGINE_REFUSAL`, `levers.ENGINE_SLOTS`, the `ordered` lever, `measured_store.engine_of` and `ledger_levers()`), `hgp/orbits.py` (#402: `orbit`, `representative`, `to_representative` → `Orientation`, `ordered_classes` / `canonical_classes`), `eri/hjk/launch_hjk.py` (#403, rule `hjk_launch`: the ordered pair stream, both modes, the `j` / `k` one-block screens, `MAX_PRIM_PAIRS` restated), `eri/hjk/kernel_hj.py` (#404, rule `hj_builder`) and `eri/hjk/kernel_hk.py` (#405, rule `hk_builder`;
