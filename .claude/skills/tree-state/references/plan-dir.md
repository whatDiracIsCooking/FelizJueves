# `src/felizjueves/plan/`

Moved verbatim from `.claude/CLAUDE.md`, "The state of the tree, its table" (indexed by `../SKILL.md`).

**live, host-side only.** Pipeline steps 1–3 of `[JEngine, v2, §6]`: `targets`, `batching` (the minimax batch split), `mild`, `dag` (one MILD DAG per batch), `sieve` (Alg. 3, off with the `no-sieve` lever), `cost` (`PlanCost`, Tables 1–3's quantities), composed by `pipeline.plan(spec)` with a JSON per-batch report. `PYTHONPATH=src uv run python -m felizjueves.plan replay literal` scores a board (exit 0 pass, 1 FAIL, 2 could not run, 3 UNSET/no candidates — `literal` exits 3 today, Tables 1–2's `exact_given_inputs` being refused); `report L n_batches` prints one plan. It counts; it emits no kernel text and compiles nothing. `recovery` recovers the inputs behind the printed cells as rules — the cut (Table 3, 40/40) and, unrecovered, the seed order (`seed_orders(widened=True)`, 58 rules, #108); `search` is the searched board's per-cell cut and per-batch seed-order permutations, climbed by `order_search` (#170, #172: the Pareto frontier, the pruned per-batch product and a seeded hill climb from the 58 rules) and selected by #171's declared rule; `pipeline.tuned_plan` builds a `tuned` Spec from that record. `optimum` (#106) is the exact `(intermediates, FLOPs)` Pareto frontier of a one-batch class by DP over Boys layers, for `L <= EXACT_MAX_L = 5` (above it `BeyondExactCeiling`, with the measured reason), and `beam` an achievable scheme above it — an upper bound on the optimum only; nothing in the pipeline imports it. `schedule` (step 4: a topological order of one batch's DAG, not text) also lives here, and is what `mmd/recurrence.py` and `mmd/kernel.py` consume.
